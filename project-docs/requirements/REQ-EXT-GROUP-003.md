# REQ-EXT-GROUP-003 群文件目录与访问控制

## 1. 分支信息

- 分支：`codex/req-ext-group-003-group-files`（群文件目录与访问控制）
- 层级：LARGE；触碰群权限、文件资产、上传下载和路径安全
- 依赖：`REQ-EXT-SEC-001`、`REQ-EXT-GROUP-001`、`REQ-EXT-FILE-001`、`REQ-EXT-FILE-002`
- 可选协同：`REQ-EXT-GROUP-002` 提供成员变化通知，但不应阻塞基础文件权限验收

## 2. 目标

为群提供逻辑文件目录，复用 `file_object/user_file` 和现有顺序上传/下载能力。群成员可按服务端授权查看、上传、下载；删除权限只授予群主或文件上传者，且成员退出/被移除后立即失权。

## 3. 数据与授权

- `group_file`（群文件逻辑关联）关联群标识、逻辑文件标识、上传者、状态和时间；禁止以客户端给出的路径作为唯一事实。
- 群文件目录使用稳定的群目录标识或受控相对路径；物理存储路径由文件资产层生成。
- 每次查看、上传、下载、删除先检查当前服务端主体是否为有效群成员。
- 删除规则：群主可删除；上传者可删除自己上传的文件；普通成员不能删除他人文件；删除必须减少逻辑引用而非直接删除共享物理对象。

## 4. 验收标准

1. 群成员可列出本群有权访问的文件元数据，包括名称、大小、上传者和时间；非成员查询失败。
2. 成员上传文件后，群目录出现一条逻辑记录；同内容可复用物理对象，不产生越权引用。
3. 群成员可下载有权文件；退出或被移除后，旧连接和新连接都不能继续列出、下载或删除群文件。
4. 群主和上传者删除权限符合规则；删除一个群引用不会影响其他用户或群的同一物理对象。
5. 路径规范化、符号链接/相对路径、超长名称和同名冲突均有负向测试；不能访问群目录之外的文件。
6. 群成员变化、一对一聊天、个人文件上传下载和秒传回归通过。

## 5. 不包含与停止条件

本分支不实现协作编辑、文件锁、版本管理、批量打包下载、群文件消息卡片和复杂 `owner/editor/viewer`（所有者/编辑者/查看者）权限。若退出/踢出后的访问撤销不是服务端即时判定，或群文件仍依赖裸路径拼接，必须停止合并。
