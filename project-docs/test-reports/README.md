## 测试执行说明

项目当前未建立自动化测试框架。所有动态测试需按以下方式执行：

1. **手动测试**：启动 Server → Client，对每个功能模块进行操作验证
2. **构建验证**：确保 qmake + make 在 Qt 5.14.2 MinGW 下编译无错误
3. **回归验证**：修复缺陷后，测试师负责回归关键功能路径
