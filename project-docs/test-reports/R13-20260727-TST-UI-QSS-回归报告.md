## 3. 残余观察与建议

### OBS-REV-001：QGraphicsOpacityEffect 对象累积 (轻微)
- **现象**：`showLoadingAnimation` 每次执行都会 `new` 一个 effect 对象挂在 Client 下。动画结束时调用 `setGraphicsEffect(nullptr)` 但没有 `delete` 或 `deleteLater()`。
- **风险**：长期运行且频繁触发登录/注册失败动画时，会累积数 KB 级别的“孤儿”对象。
- **建议**：在 `client.cpp:401` 处，将 `setGraphicsEffect(nullptr)` 扩展为：
  ```cpp
  auto *eff = ui->loadingLabel->graphicsEffect();
  ui->loadingLabel->setGraphicsEffect(nullptr);
  if (eff) eff->deleteLater();
  ```
