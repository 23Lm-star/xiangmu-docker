## 3. 新增缺陷

### BUG-TST-CLIENT-001 — 严重（阻塞）

| 项目 | 内容 |
|------|------|
| **现象** | Client 登录成功后，主界面文件列表加载时崩溃 |
| **崩溃信息** | `pure virtual method called / terminate called without an active exception / exit code 3` |
| **触发点** | 收到 `FLUSHFILE_RESPOND`(type=24) 后，`flushfile()` → `updateCurrfile()` 过程 |
| **数据验证** | 文件列表数据正确（`FileInfo` 解析正常），非数据损坏导致 |
| **根因推测** | QObject 生命周期/虚函数表被破坏的预存缺陷 |
| **与 POOL 关系** | **无关** — POOL-001~008 均为 Server 端修改或 protocol.h 字段仅改名。该崩溃为预存问题 |
| **状态** | **待确认** |
