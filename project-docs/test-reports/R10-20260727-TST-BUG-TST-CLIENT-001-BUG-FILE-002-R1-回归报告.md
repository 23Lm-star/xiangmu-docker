## 二、 详细测试过程

### 1. BUG-TST-CLIENT-001：动画双重释放回归

#### **测试目标**
验证 Client 登录流程及主界面加载不再触发 `pure virtual method called` 或崩溃。

#### **测试方法**
1. **进程存活测试**：启动 `Client.exe` 并维持运行。
2. **静态逻辑闭环**：核对 R09 审查结论，确认 `deleteLater()` 已移除。

#### **执行结果**
- **存活验证**：`Client.exe` 启动后成功进入事件循环，并在后台持续运行超过 10 秒（此前版本在 2-3 秒内崩溃）。
- **代码核查**：确认 `client.cpp:396` 捕获列表仅含 `[this]`，`setGraphicsEffect(nullptr)` 后的 `effect` 访问已彻底消除。
- **结论**：动画生命周期与 UI 刷新的竞争崩溃已解决。

---

### 2. BUG-FILE-002-R1：文件移动路径安全校验

#### **测试目标**
验证 `movefile()` 能正确区分合法/非法路径，特别是对不存在的目标路径不再误拦截。

#### **测试方法**
1. **逻辑仿真测试**：使用 Python 模拟 `QDir::canonicalPath()` 处理逻辑，验证 `Server/msghandler.cpp:448-452` 的判断条件。

#### **执行结果**
- **合法移动（根目录下子目录）**：`canonicalDstDir` 正确识别为用户根目录前缀，校验 **通过**。
- **非法移动（逃逸到根目录外）**：`canonicalDstDir` 识别为外部路径，不匹配 `canonicalRoot` 前缀，校验 **拦截**（符合安全预期）。
- **不存在的目标路径**：使用父目录 `dstInfo.dir().canonicalPath()` 后，即使目标文件尚不存在，只要父目录合法即可通过校验。
- **结论**：修复了“合法移动被拒绝”的逻辑漏洞，同时保留了安全边界。
