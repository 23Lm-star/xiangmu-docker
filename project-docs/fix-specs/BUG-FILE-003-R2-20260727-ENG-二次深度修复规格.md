# BUG-FILE-003 二次深度修复规格

## 缺陷编号
BUG-FILE-003（文件移动重名冲突及重命名失败）

## 问题原因

审查 `Server/msghandler.cpp:movefile()` 发现以下技术缺陷：

### R1（已修复/部分残留）
1. **路径拼接不一致**：第 444 行 `userRoot` 仍使用 `QString("%1/%2")` 手动拼接，未统一使用 `QDir::filePath()`。
2. **重名循环内路径硬编码**：第 481 行 `finalDstPath = QString("%1/%2(%3)%4")` 使用 POSIX 分隔符 + 字符串格式化拼接，在 Windows 下 `QFile::rename()` 可能因路径分隔符问题失败（底层调用 `MoveFileW`）。
3. **无错误明细输出**：第 487-494 行使用 `QFile file;`（空文件对象）调用 `file.rename()`，仅检查布尔返回值，失败时不打印 `errorString()`。降级 `copy` 路径同样不打印错误。
4. **QFileInfo 缓存不一致**：第 472 行 `QFileInfo checkInfo(finalDstPath)` 创建后，循环内第 480 行使用静态 `QFileInfo::exists()`，两者返回可能不一致。

## 修复方案

### 修改文件
- `Server/msghandler.cpp`：`movefile()` 函数重写

### 具体修改

1. **用户根目录路径构造** → 使用 `QDir::cleanPath()` + `QFileInfo::filePath()`
2. **重名后缀路径构造** → 使用 `QDir(dirPath).filePath()` 委托 Qt 处理分隔符
3. **实例化 rename + 错误日志** → `QFile srcFile(srcPath); srcFile.rename(dstPath); if(!ok) qDebug() << srcFile.errorString();`
4. **copy 降级 + 错误日志** → `QFile::copy(src, dst)` 失败时打印 errorString
5. **一致性校验** → 移除多余的 `checkInfo` 变量，统一使用 `QFileInfo::exists()`

### 不可变约束
- 重名自动追加 (n) 后缀策略不变
- PDU 协议不变（仍返回 bool）
- 输入输出接口签名不变

## 影响范围
- 仅影响 `Server/msghandler.cpp:movefile()` 函数
- 不需要修改客户端或其他模块

## 验证建议
1. 编译验证（`qmake && mingw32-make`）
2. 模拟重名移动：目标目录已有同名文件，验证自动追加 (1)(2) 后缀
3. 模拟跨盘移动（若存在）：验证 rename 失败后 copy+remove 降级
4. 检查日志输出包含 `errorString:` 信息
