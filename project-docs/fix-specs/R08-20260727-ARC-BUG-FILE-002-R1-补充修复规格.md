# 修复规格：BUG-FILE-002-R1 补充修复（目标父目录校验）

## 1. 总则

根据 `project-docs/bug-reports/R08-20260726-REV-BUG-FILE-002-R1-二次审查.md`，此前修正了变量名（`canonicalSrc` -> `canonicalDst`），但因文件移动目标路径在移动发生前不存在，`canonicalFilePath()` 会返回空字符串，导致安全检查永远失败，正常的移动操作被全部拦截。

正确的做法是校验目标路径的**父目录**是否合法（即是否处于用户文件根目录以内）。

## 2. 变更清单总览

| 文件 | 变更类型 | 范围 | 说明 |
|---|---|---|---|
| `Server/msghandler.cpp` | 修改 | `movefile()` | 更改目标路径安全校验逻辑，使用父目录进行校验 |

## 3. 执行顺序与详细规格

### 阶段 1：修改 `Server/msghandler.cpp`

**目标文件**：`Server/msghandler.cpp`

**修改位置**：`movefile()` 方法内部，目标路径校验（约在 446-448 行）

**修改内容**：
将提取 `dstPath` 的 `canonicalFilePath()` 更改为提取其所在的目录 `dir()` 的 `canonicalPath()`，并利用该路径进行前缀校验。

**代码参考**（供比对）：

**修改前**（包含错误的安全校验逻辑）：
```cpp
    QString canonicalDst=dstInfo.canonicalFilePath();
    if(canonicalDst==canonicalRoot || canonicalDst.startsWith(canonicalRootPrefix)){
```

**修改后**：
```cpp
    // 确保目标路径的父目录也在用户根目录内
    QDir dstDir = dstInfo.dir(); // 获取父目录
    QString canonicalDstDir = dstDir.canonicalPath(); // 父目录必定存在
    
    if(!canonicalDstDir.isEmpty() && 
      (canonicalDstDir == canonicalRoot || canonicalDstDir.startsWith(canonicalRootPrefix))){
```

*注意*：保持 L442-444 的外层源路径校验不变。
