# REQ-UX-001 客户端可用性与视觉统一

- 日期：2026-10-01

## 来源

主人实机反馈（`dist/` 运行）5 条：

1. 在线用户列表中点击用户条目没有任何反应（后更正：双击也没有任何弹窗响应）。
2. 用户文件夹内部没有显示任何用户目录，服务端刷屏 `[flushfile] 拒绝越权列目录 conn=2 : "./filesys/wcy"`。
3. 客户端群聊界面展示混乱，看不懂展示逻辑，无法正常使用。
4. 所有 UI 界面背景统一为登录界面同款背景，字体统一白色，保证可读。
5. 界面尺寸扩大到当前四倍，字体同步放大。

## 验收标准（业务语言）

- **A1 在线用户**：点击在线用户条目必须有肉眼可见的反馈；双击弹出"添加好友"确认框，确认后无论成功或失败都要弹出结果提示（不再静默）。
- **A2 用户目录**：任何已注册账号登录后，服务端保证其个人目录存在；文件页能正常列出该账号目录内容，新建目录/上传不再被"越权"误拒。
- **A3 群聊**：消息能一眼分清"我"与"他人"，显示昵称与时间，长文本自动换行；系统消息居中且视觉弱化；不再出现"群水位/服务端已读/本地未读"这类原始术语；发送中/失败状态用可见标记表达，不混进正文。
- **A4 主题**：所有窗口背景与登录页一致，文字白色/高对比，消除"浅底浅字"看不清的问题。
- **A5 尺寸**：所有窗口面积放大约 4 倍（长宽各约 2 倍），字号同步放大且不溢出。
