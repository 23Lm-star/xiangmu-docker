## 残余观察

### OBS-REV-001：`showLoadingAnimation` 中 QGraphicsOpacityEffect 对象累积（轻微）

| 项目 | 详情 |
|------|------|
| **代码位置** | `client.cpp:381,401` |
| **观察** | 每次调用 `showLoadingAnimation()` 都 `new QGraphicsOpacityEffect(this)`（line 381），父对象为 `this`（Client）。fadeOut 完成后调用 `setGraphicsEffect(nullptr)`（line 401）移除效果，但**不 delete 对象**。多次调用（如登录失败后重试成功）会在 Client 生命周期内累积孤儿 effect 对象。 |
| **影响** | 仅在 `showLoadingAnimation` 被多次调用时发生（每次 ~数 KB），窗口关闭时随 Client 析构清理。非本轮引入。 |
| **严重等级** | 轻微（不阻塞、不崩溃） |
| **建议** | 在 `setGraphicsEffect(nullptr)` 后添加 `eff->deleteLater()` 或复用同一个 effect 对象。 |
| **与本轮的关系** | 与本轮修复（悬空指针）正交。本轮修复是正确的，但未覆盖该累积问题。 |
