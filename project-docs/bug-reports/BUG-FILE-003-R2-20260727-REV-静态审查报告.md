#### ✅ Lines 471-487：重名循环
```cpp
QString finalDstPath = dstPath;
if (QFileInfo::exists(finalDstPath)) {
    QFileInfo checkInfo(finalDstPath);    // 仅用于提取 baseName/suffix
    QDir parentDir = checkInfo.dir();
    QString baseName = checkInfo.completeBaseName();
    QString suffix = checkInfo.suffix();
    if (!suffix.isEmpty()) suffix = "." + suffix;
    int count = 1;
    do {
        QString numberedName = QString("%1(%2)%3").arg(baseName).arg(count++).arg(suffix);
        finalDstPath = parentDir.filePath(numberedName);
    } while (QFileInfo::exists(finalDstPath));
    qDebug() << "文件移动重名，自动重命名为:" << finalDstPath;
}
```
- `checkInfo` 仅用于提取文件名成分，不再参与循环条件 ✅
- 循环条件统一使用 `QFileInfo::exists()` ✅
- 路径构造使用 `parentDir.filePath()` ✅
- `numberedName` 字符串拼接（非路径拼接）— 文件名构造可接受 ✅
- ⚠️ `count` 无上限 — **BUG-REV-FILE-003**（轻微）

#### ⚠️ Lines 489-505：Rename + Copy 降级 — 发现 BUG-REV-FILE-001, BUG-REV-FILE-002
```cpp

    if (!ret) {
        qDebug() << "copy 降级也失败, errorString:" << srcFile.errorString() ...
```

- 实例化 `QFile srcFile(srcPath)` 获取 errorString ✅

- ⚠️ **BUG-REV-FILE-001**：copy 失败时仍打印 `srcFile.errorString()` — 这是 rename 失败的错误，不是 copy 失败的错误
- ⚠️ **BUG-REV-FILE-002**：`QFile::remove(srcPath)` 无返回值检查 — remove 失败时源文件残留但函数返回 true
