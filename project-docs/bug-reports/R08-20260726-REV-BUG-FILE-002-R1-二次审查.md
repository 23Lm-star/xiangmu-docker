## 审查详情

### 修复内容回顾

工程师在 `Server/msghandler.cpp:448` 将 `canonicalSrc` 改为 `canonicalDst`，使目标路径校验从重复的源路径校验更正为正确的目标路径变量。

**变更前**（bug）：
```cpp
QString canonicalDst=dstInfo.canonicalFilePath();
if(canonicalSrc==canonicalRoot || canonicalSrc.startsWith(canonicalRootPrefix)){
```
→ 外层 `if` 校验了源路径（L442-444），内层 **再次校验源路径**，目标路径校验完全缺失。

**变更后**：
```cpp
QString canonicalDst=dstInfo.canonicalFilePath();
if(canonicalDst==canonicalRoot || canonicalDst.startsWith(canonicalRootPrefix)){
```
→ 外层 `if` 校验源路径，内层 `if` 校验目标路径，各司其职。

### 机械正确性：✅

变量名修正正确。`canonicalSrc` → `canonicalDst` 单行变更已应用，无其他文件被修改。

### 语义正确性：❌ 存在隐蔽问题

`canonicalFilePath()` 的语义是：**返回指定路径的规范化绝对路径；若文件不存在则返回空字符串**。

`movefile()` 的目标路径 `dstPath` 是文件移动的**目标位置**——文件尚不存在于此路径。因此：

```cpp
QString canonicalDst = dstInfo.canonicalFilePath(); // 始终返回 ""
if (canonicalDst == canonicalRoot || canonicalDst.startsWith(canonicalRootPrefix)) {
    // 条件永远不成立 → 移动操作永远不会执行
}
```

**效果**：`movefile()` 的路径合法性校验在实际使用中会拒绝所有合法操作——因为目标路径尚不存在，`canonicalDst` 为空字符串，内层 `if` 条件始终为假，`ret` 保持 `false`，文件移动永不发生。

### 正确做法

应校验目标路径的**父目录**的规范路径：

```cpp
QFileInfo dstInfo(dstPath);
QDir dstDir = dstInfo.dir();                      // 获取父目录（不要求文件存在）
QString canonicalDstDir = dstDir.canonicalPath(); // 父目录一定存在
if (canonicalDstDir == canonicalRoot || canonicalDstDir.startsWith(canonicalRootPrefix)) {
    // 目标文件在用户根目录内，安全
}
```

## 影响范围

- 功能影响：`movefile()` 路径校验合法穿越的情况下，**移动操作被正确拦截**（安全面有利），但也阻止了**正常使用**
- 安全面：当前条件下不会发生路径穿越（因 `canonicalDst=""` 不满足任何条件）
- 安全面补充：父目录校验修复后，仍应防范路径穿越攻击
- 回归面：`movefile()` 当前所有调用路径均受影响；不受影响的功能包括 `sharefilemove()`（仍走 `QFile::copy`）、文件上传/下载

---

## 判断依据

1. Qt 官方文档：`QFileInfo::canonicalFilePath()` — *"Returns the canonical path, i.e. a path without symbolic links or redundant "." or ".." elements. If the file does not exist, canonicalFilePath() returns an empty string."*
2. `movefile()` 调用时刻文件尚未在目标路径创建——这是文件移动的基本语义
3. 外层 `if` 的源路径校验 `canonicalSrc` 使用 `canonicalFilePath()` 是正确的（源文件存在），不应修改

---

## 修正建议

将 `Server/msghandler.cpp:446-448` 改为校验目标父目录的规范路径：

```
//确保目标路径也在用户根目录内
QFileInfo dstInfo(dstPath);
QDir dstDir = dstInfo.dir();                            // 父目录
QString canonicalDstDir = dstDir.canonicalPath();       // 父目录规范路径
if(!canonicalDstDir.isEmpty()
    && (canonicalDstDir==canonicalRoot
        || canonicalDstDir.startsWith(canonicalRootPrefix))){
```
