# 决策记录：connect.config 外部化 vs Qt Resource 嵌入

> 背景：BUG-DB-002-R2

## 问题描述

当前 `connect.config` 通过 Qt Resource 机制（`.qrc` 文件）编译嵌入到服务端二进制中：
```
QFile file(":/connect.config");
```
这意味着部署后修改数据库密码、IP 地址等配置需要重新编译。

## 决策

**延后处理，当前接受 Qt Resource 嵌入方案。**

## 理由

1. 项目处于开发阶段，重新编译是正常操作
2. 改为外部文件读取需要额外设计：默认搜索路径、回退策略、权限检查
3. 跨平台路径差异增加复杂性
4. 当前问题不影响 BUG-DB-002 的修复目标（消除源码中硬编码密码）

## 未来改进方向

- 部署阶段应改为从可执行文件所在目录加载外部 `connect.config`
- 搜索顺序建议：`./connect.config` → 编译时嵌入的默认值
- 若配置文件不存在且是首次部署，交互式引导配置或生成空白模板
